# Официальные фоны карты

Только фоны территорий племён **Гроза** и **Тени**. Сюда кладут картинки локаций; в редактор они сами не подставляются.

## Имена файлов

Одно имя — одна локация. Регистр нижний, пробелы заменить на `-`:

`берёзовая-роща.jpg`

Другие расширения (`png`, `webp`) тоже можно. Каталог всех локаций здесь не ведём — кладите файл, когда он есть.

## Кто это использует

Игроки на своей карте по-прежнему вставляют любой URL в поле «Фон». Эта папка им не нужна.

## Ссылка после публикации

Vite отдаёт `public/` как корень сайта (`base: './'`), путь относительный.

После выкладки на GitHub Pages (`cw-mod`) вставьте в «Фон» один из вариантов:

- Pages: `{pages-origin}/assets/гроза/берёзовая-роща.jpg`
- raw: `https://raw.githubusercontent.com/{org}/{repo}/{branch}/public/assets/гроза/берёзовая-роща.jpg`

Для Тени — `/assets/тени/…`. URL копируете сами.
