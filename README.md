# Карта CatWar (`cw-map`)

Статический просмотрщик и редактор карт локаций CatWar. Вопросы, предложения и помощь: [профиль CatWar](https://catwar.su/cat965285) и [Telegram](https://t.me/polexka).

Сайт: [https://cw-mod.github.io/cw-map/](https://cw-mod.github.io/cw-map/). Репозиторий: [cw-mod/cw-map](https://github.com/cw-mod/cw-map).

## Запуск

```bash
cd cw-map
npm install
npm run dev
```

Сборка: `npm run build`. Предпросмотр сборки: `npm run preview`.

## Адреса

| Путь | Что это |
| --- | --- |
| `/` | Просмотр. По умолчанию канонический пресет «Горы». Поиск кратчайшего пути A→B по числу направленных переходов. |
| `/edit` | Редактор. Черновик живёт в `sessionStorage`, канонический JSON не перезаписывается. |
| `/#m=<сжатая карта>` | Чужая карта **только для просмотра**. В редактор она сама не попадает. |

«Копия себе» на странице просмотра копирует текущую карту в черновик и открывает `/edit`. «Поделиться» копирует **view**-URL с `#m=` (lz-string). Если ссылка не влезает, скачайте JSON.

Для SPA на GitHub Pages в `public/404.html` есть редирект на `index.html`. `vite.config` использует `base: './'`.

## Данные

Карта: `{ version, name, comment?, locations[], edges[] }`.

- Локация: стабильный `id` (`loc_…`), имя (не уникально), `x/y` на холсте, `tribes`: `grosa | veter | teni | reka` (0 = нейтраль, несколько племён можно).
- Сетка всегда 10×6. Проходимость не хранится: клетка «горит», если на ней конец ребра.
- Рёбра только направленные: `{ id, fromLocationId, fromCell: {x,y}, toLocationId, toCell: {x,y} }`. Двусторонний переход в UI = два ребра. Петля = `fromLocationId === toLocationId` (рисуется, в BFS не входит).

Канон «Горы»: `public/maps/gory.json` и бандл `src/data/gory.json`. Это единственный официальный пресет, он же открывается на `/`. Из UI его нельзя сохранить поверх файлов.
